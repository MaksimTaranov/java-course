# Лабораторная работа №1. Матрицы комплексных чисел

## Описание

В рамках лабораторной работы разработана программа на Java для выполнения математических операций над матрицами комплексных чисел.

## Функциональность

Программа поддерживает следующие операции:

- Ввод и изменение элементов матрицы.
- Сложение матриц.
- Умножение матриц.
- Деление матриц (при наличии обратной матрицы).
- Транспонирование матрицы.
- Вычисление определителя матрицы (через разложение по строке).

### Описание классов

| Класс | Назначение |
|---|---|
| `ComplexNumber` | Представление комплексного числа и реализация арифметических операций над комплексными числами. |
| `Matrix` | Представление матрицы комплексных чисел и реализация операций над матрицами. |
| `Main` | Консольный интерфейс, обработка пользовательского ввода и управление выполнением программы. |
